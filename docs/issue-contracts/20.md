# GitHub issue #20 — [Data] Import the complete product catalog for every supported branch

- Source: https://github.com/eyal1990/super-market/issues/20
- State when synchronized: open
- Synchronized at: 2026-08-30T14:30:36.765Z

## User problem
The app contains only a handful of fixture products, so it cannot answer real shopping questions.

## Scope
Make the supported retailer/branch catalogs complete and maintainable through the existing portable ingestion pipeline, while keeping fixtures for local development.

## Acceptance criteria
- The catalog pipeline imports all products exposed by each supported retailer source, not a manually selected sample.
- Products retain barcode/source identity, brand, size/unit, category when available, branch availability, current price, promotions, source, and freshness.
- Full and incremental imports are idempotent and cannot replace valid data with an empty/malformed source.
- Duplicate/weighted products and retailer-specific identifiers have deterministic handling.
- The UI/API expose catalog completeness/freshness limitations instead of claiming unsupported coverage.
- A representative fixture test proves a full catalog is searchable and branch-specific availability is preserved.
- The source matrix documents exactly which retailers/branches are covered and what remains unavailable.
