# GitHub issue #22 — [Location] Support arbitrary Israeli address entry and geocoding

- Source: https://github.com/eyal1990/super-market/issues/22
- State when synchronized: closed
- Synchronized at: 2026-08-30T18:52:04.669Z

## User problem
Only two hard-coded Tel Aviv addresses are available. Users must be able to enter any address in Israel.

## Scope
Replace fixture-only address matching with a provider-neutral, server-side geocoding flow and nearby-branch resolution. Keep exact addresses ephemeral by default.

## Acceptance criteria
- Hebrew and Latin input can search arbitrary Israeli street, number, city, and postal-address combinations.
- Results are selectable and include a human-readable label plus coordinates/precision metadata needed for branch matching.
- Ambiguous, empty, out-of-coverage, timeout, and rate-limit states are explicit and actionable.
- Geocoder access is server-side, cached, rate-limited, and configured through environment variables.
- The UI never permanently stores an exact address unless the user explicitly opts in.
- Tests use fixtures/mocks and do not require a live geocoder.

Legacy #11; use the privacy constraints in #17.
