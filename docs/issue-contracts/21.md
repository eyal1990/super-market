# GitHub issue #21 — [Product] Start with an empty basket

- Source: https://github.com/eyal1990/super-market/issues/21
- State when synchronized: closed
- Synchronized at: 2026-08-30T18:52:04.416Z

## User problem
The site currently opens with milk, cereal, and tomatoes already in the basket. A new visitor should decide what to buy.

## Scope
Remove the hard-coded initial basket while preserving a returning anonymous user's locally saved basket when one exists.

## Acceptance criteria
- A first visit with no saved basket renders an empty basket and a zero item count.
- Adding a product updates the basket immediately.
- Reloading preserves only products the user actually added.
- Corrupt, outdated, or invalid local basket data is ignored safely.
- Empty-basket UI explains the next action and is usable in Hebrew/RTL.

## Dependencies
The first-run location/store issue should be implemented in the same onboarding flow.
