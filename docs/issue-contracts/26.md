# GitHub issue #26 — [Product] Require address or location before showing a selected store

- Source: https://github.com/eyal1990/super-market/issues/26
- State when synchronized: closed
- Synchronized at: 2026-08-30T18:52:05.154Z

## User problem
The site currently selects the first store and displays a Tel Aviv location before the user has provided any location.

## Scope
Make location the first meaningful setup step and remove all implicit default store selection.

## Acceptance criteria
- A new visitor has no selected store and sees a clear Hebrew/RTL prompt to enter an address or optionally use browser location.
- No branch is shown as selected, and price/basket comparison actions are gated until a location is resolved.
- Returning local state may restore a previously chosen location/store only when it is valid and explicitly saved.
- Denied location permission and dismissed setup have clear next steps.
- The flow works on mobile and desktop without trapping keyboard or screen-reader users.

## Dependencies
#22 and legacy #11/#14.
